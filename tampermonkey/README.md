# Tampermonkey Helpers

This folder contains browser userscripts for manually reviewed Idaho Department of Labor weekly certification pages.

The scripts are intentionally review-first:

- They add helper buttons to the page.
- They fill known fields only after you click a helper button.
- They do not click `Next`, `Submit`, or certification buttons.
- They do not store Idaho portal credentials or session data.

## Install

1. Open the Tampermonkey dashboard in Chrome.
2. Create a new script.
3. Replace the starter content with `idaho-weekly-certification-helper.user.js`.
4. Save the script.
5. Open the Idaho weekly certification flow.

The helper appears as a right-side drawer on matching certification pages. Click the small `WSR` tab to show or hide the full-height helper panel.

## Supported Pages

### Step 1 - Work Availability

The current script supports the Work Availability page:

`/ClaimantPortal/CertificationApplication/WorkAvailability`

Normal weekly answers:

| Question | Answer |
|---|---|
| Able To Work | Yes |
| Available for Work | Yes |
| Away from Area | No |
| Refused Work | No |
| Missed Work | No |
| Attended School or Training | No |
| Quit Job | No |
| Fired from Job | No |

Use `Check current selections` before and after filling if you want a quick sanity check. After filling, review the page yourself and click `Next` manually.

### Step 2 - Income

The current script supports the Income page:

`/ClaimantPortal/CertificationApplication/Income`

Normal weekly answers:

| Question | Answer |
|---|---|
| Worked for Employer | No |
| Self Employed | No |
| Other Income | No |

The helper only fills those top-level visible answers. It does not touch hidden employer, self-employment, tips, overtime, or other-income detail fields unless a future weekly situation requires a different answer and we explicitly add that flow.

### Step 3 - Work Search Actions

The current script supports the Work Search Actions list page:

`/ClaimantPortal/CertificationApplication/WorkSearchContacts`

Use this page to import the local CSV generated by the CLI:

`outputs/idaho_work_search_log.csv`

The CSV is read with the browser's local file picker and stored in the portal page's `localStorage`. It is not uploaded anywhere by the userscript. Re-import the CSV after regenerating or editing it.

CSV rows are shown oldest first by `action_date`, with company and job title used as tie breakers for rows on the same day.

After importing the CSV, click `Add Work Search Action` in the Idaho portal and choose:

`Completed and submitted application to employer`

The add-action form is also supported:

`/ClaimantPortal/CertificationApplication/AddWorkSearchContact`

On that form, choose a current-week CSV row in the helper panel and click `Fill selected CSV work-search row`.

CSV fields mapped into the portal:

| Portal field | CSV source |
|---|---|
| Action Date | `action_date` |
| Company Name | `company` |
| Company Address | `mailing_address_line_1` |
| Address Line 2 | `mailing_address_line_2` |
| Country | United States of America |
| City | `city` |
| State | `state` |
| ZIP Code | first 5 digits from `zip` |
| Company Website | `employer_website` |
| Company Email | email parsed from `employer_contact` or `source_sender` |
| Type of Work or Job Title | `job_title` |
| Application Submitted | Yes |
| Additional Information | Awaiting response from the employer |

The helper also attempts to fill optional contact phone and contact name when they can be derived cleanly from the CSV. Review every field before clicking `Save Action` manually.

### Submit - Certification Acknowledgements

The current script supports the final Submit page:

`/ClaimantPortal/CertificationApplication/Submit`

The helper can mark the three acknowledgement boxes as agreed:

| Section | Action |
|---|---|
| Recorded Answers | Check `I agree.` |
| Accurate Answers | Check `I agree.` |
| Penalty | Check `I agree.` |

Use `Review acknowledgement status` before and after filling. Review the full page yourself before clicking `Submit Certification Application` manually.

## Testing As We Go

Because submitted weekly certifications cannot be reopened until the next filing window, test each page only while it is available:

1. Open the page.
2. Confirm the helper detects the page name.
3. Click `Check current selections`.
4. Click the fill button.
5. Review every selected answer.
6. Click `Next` manually only when the answers are correct.

For each new page, capture a screenshot and the relevant `<form>...</form>` HTML before moving on. That gives us enough information to add the next page helper without needing to revisit the submitted page.
